# Loan Origination Form Fields

This document captures the required loan application form fields for the Microfinance Loan Origination System.

## 1. Customer Details
- Customer Number
- First Name
- Middle Name
- Last Name
- Date of Birth
- Gender
- Marital Status
- Mobile Number
- Alternate Number
- Email
- National Identity Number
- Address Line 1
- Address Line 2
- City
- State
- Postal Code
- District
- Country
- Occupation
- Monthly Income
- Household Income
- Existing Liabilities
- KYC Status

## 2. Branch / Center Details
- Branch Code
- Branch Name
- Center Code
- Center Name
- Center Meeting Day
- Loan Officer

## 3. Product Details
- Product Code
- Product Name
- Product Type
- Loan Amount Requested
- Purpose of Loan
- Tenure in Months
- Interest Rate
- Repayment Mode
- Applicant Category
- Credit Score
- Risk Grade

## 4. Loan Information
- Loan Number
- Loan Application Date
- Disbursement Date
- Sanction Amount
- Approved Amount
- EMI Amount
- Moratorium Days
- Grace Period
- Security Type
- Collateral Details
- Purpose Description

## 5. Guarantor Details
- Guarantor Name
- Relationship
- Date of Birth
- Mobile Number
- Address
- Monthly Income
- Employment Status
- KYC Status

## 6. Document Checklist
- Identity Proof
- Address Proof
- Income Proof
- Bank Statement
- Photo
- Signature
- Business Proof
- Property Proof
- Guarantor Documents
- Declaration Forms

## 7. Business / Income Validation
- Business Nature
- Annual Turnover
- Loan Cycle
- Existing Loan Outstanding
- Average Monthly Sales
- Average Monthly Profit
- Cash Flow Source
- Household Expenditure

## 8. Credit / Risk Details
- CRS Score
- Risk Band
- Policy Exception
- Maximum Eligibility

## 9. Approval Workflow
- Application Stage
- Creator User
- Authorizer User
- Approval Status
- Approval Comments
- Approved By
- Approved Date

## 10. System Metadata
- Created By
- Created At
- Updated By
- Updated At
- Audit Trail ID
